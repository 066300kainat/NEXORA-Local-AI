\# NEXORA AI



NEXORA AI is a local AI chat application built with Streamlit and Ollama. It uses the Qwen2.5 0.5B large language model to generate responses locally.



\## Features



\- Local LLM inference using Ollama

\- Qwen2.5 0.5B model

\- Interactive Streamlit chat interface

\- Multiple conversations

\- Persistent conversation history

\- New Conversation option

\- Clear All History reset functionality

\- Ollama online/offline status

\- Fully local AI inference



\## Technologies Used



\- Python

\- Streamlit

\- Ollama

\- Qwen2.5 0.5B

\- Requests

\- JSON
